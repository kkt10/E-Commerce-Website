# E-Commerce-Website
Spring 3, Spring Boot 6, React, MYSQL

To run this file, open it in Vs code for React, ie the frontend part, and the backend part on Spring sts or Eclipse with sts intalled.
Ensure that you dont have the same database name, from the application.properties of the Backend.
Reacts scripts not installed issue: npm install react-scripts --save
The basic import from existing maven repository, and run to run and npm start to start the server.
ensure that the Basepath for the images is correct replace the \ backslashes with the / forward slashes for the path.
Enjoy!
